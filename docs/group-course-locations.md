## 银泰城校区数据库记录

在 CloudBase 的 `campus` 集合新增以下记录，`_id` 使用数据库自动生成。名称必须为“银泰城校区”，与前端位置配置一致；已有同名记录时直接更新，避免重复新增。

```json
{
  "name": "银泰城校区",
  "enabled": true,
  "sortOrder": 5,
  "bookingManaged": false
}
```

此配置按银泰城不联动订场占用准备；`sortOrder` 可按现有校区顺序调整。`bookingManaged=false` 且该校区没有任何 CloudBase `court` 记录时，服务端提供默认1号场、2号场；已有场地记录则只使用真实场地列表。地址与经纬度由前端配置读取，不需要加入 `campus` 记录。

新增校区的选择项来自数据库；地址与地图支持需要发布本次小程序前端改动，无需部署云函数。本文仅提供数据库记录，未在线写入。
